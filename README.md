# 连点器 (AndroidAC)

一个简洁、**完全离线**的 Android 连点器（自动点击）工具。可添加多个编号点击点，基于无障碍服务（`dispatchGesture`）按顺序循环点击，配合悬浮控制栏随时开始/停止。

> 本应用不读取屏幕内容、不联网、不收集任何数据。

## 功能特性

- **多个点击按钮**：用「＋」添加编号点击点，分别拖动到目标位置，最多 50 个；「－」删除最后一个，至少保留 1 个。
- **顺序循环**：按 `1 → 2 → 3 → … → 1` 重复点击；每次重新启动都从 1 号开始。
- **悬浮控制栏**：开始/停止、添加、删除、编辑/完成；拖动播放按钮可移动整个控制栏。
- **可调点击间隔**：每次点击完成后等待设定时间（20–2000 ms），再点击下一个编号；单个点击点仍可照常连点。
- **自动保存**：点击点数量、顺序和位置保存在本机，重新开启无障碍服务后恢复。
- **点击穿透**：锁定后点击落到下层应用，不会误触标记本身。
- **轻量常驻**：悬浮窗由无障碍服务上下文创建，无需额外前台服务保活。

## 安装

1. 在 [Releases](../../releases) 页面下载最新的 APK。
2. 在手机上允许「安装未知来源应用」后安装。
3. 首次启动按引导开启两项权限：
   - **① 悬浮窗权限**（`SYSTEM_ALERT_WINDOW`）
   - **② 无障碍服务**

> ⚠️ 侧载（非应用商店）安装时，Android 13+ 开启无障碍前可能被「受限设置」拦截。
> 请到 **设置 → 应用 → 连点器 → 右上角菜单 → 允许受限设置**，再回到无障碍页面开启本服务。

## 使用方法

1. 开启权限并打开需要连点的应用，屏幕上会出现 1 号点击点与悬浮控制栏。
2. 点 **＋** 添加点击点，进入定位模式后分别拖动编号标记，让十字中心对准目标按钮。
3. 点 **完成** 锁定位置，或直接点 **▶** 开始；锁定时点击会穿透所有标记到下层应用。
4. 点 **▶ / ■** 开始或停止按编号循环点击。控制栏需要避开目标位置，可拖动播放按钮移动。
5. 要调整位置，点 **编辑**（也可长按播放按钮）；点 **－** 删除最后一个编号。添加、删除或进入编辑时会先停止连点。

切换到其他应用或系统弹窗时会暂停点击，返回启动时的应用后继续。屏幕方向/尺寸变化时会停止并进入定位模式，需要重新确认位置后手动启动。停止时已发出的单次手势可能完成，但不会继续发出下一次。

## 构建

Android 项目，使用 Gradle (Kotlin DSL)：

| 项目 | 值 |
| --- | --- |
| `applicationId` | `com.casual.autoclicker` |
| `minSdk` | 24 |
| `targetSdk` | 32 |
| `compileSdk` | 33 |

```bash
./gradlew assembleDebug      # 生成 debug APK
./gradlew assembleRelease    # 生成 release APK（需配置签名）
./gradlew testDebugUnitTest lintDebug  # 点击顺序/调度回归测试及静态检查
```

构建需要 JDK 11 或 17、Android SDK Platform 33。Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`；覆盖已有安装时需使用相同的签名证书。

## 手动验证

- 添加 3 个点击点并拖到不同目标，验证顺序为 `1 → 2 → 3 → 1`，单点时正常重复。
- 点击停止后等待超过一个间隔，确认不再点击；快速停止/启动仍从 1 号开始。
- 运行中添加、删除或编辑应停止；删除到 1 个后「－」禁用。
- 停用/重启无障碍服务，确认编号、位置和间隔恢复。
- 在 Android 12 及以上确认点击可穿透标记（包括标记重叠时），切换应用暂停、返回继续。
- 旋转屏幕后确认停止并进入编辑，所有按钮仍可操作；校准位置后可重新启动。
