# 连点器 (AndroidAC)

一个简洁、**完全离线**的 Android 连点器（自动点击）工具。可添加多个编号点击点，基于无障碍服务（`dispatchGesture`）按顺序循环点击，配合悬浮控制球随时开始/停止。

> 本应用不读取屏幕内容、不联网、不收集任何数据。

## 功能特性

- **多个点击按钮**：长按控制球展开「＋ / －」，可添加并拖动多个目标点，最多 50 个；「－」删除最后一个，至少保留 1 个。
- **顺序循环**：按 `1 → 2 → 3 → … → 1` 重复点击；每次重新启动都从 1 号开始。
- **原版悬浮控制球**：平时只有一个 45dp 圆形开始/停止按钮（16sp 图标）；长按才展开两个同样大小的「＋ / －」圆形按钮，再次长按收起。主球可照常拖动，展开时主球位置不变。
- **可调点击间隔**：每次点击完成后等待设定时间（20–2000 ms），再点击下一个编号；单个点击点仍可照常连点。
- **原版目标点样式**：保留 28dp 十字准星及原来的黑白描边、透明度和定位高亮；多个目标点时显示小号顺序编号。
- **自动保存**：点击点数量、顺序和位置保存在本机，重新开启无障碍服务后恢复。
- **点击穿透**：锁定后点击落到下层应用，不会误触标记本身。
- **只需一次授权**：控制球使用无障碍专用悬浮窗，不申请“显示在其他应用上层”权限，也无需额外前台服务保活。

## 安装

1. 在 [Releases](../../releases) 页面下载最新的 APK。
2. 在手机上允许「安装未知来源应用」后安装。
3. 首次启动只需按引导开启 **无障碍服务**。应用不再申请普通悬浮窗权限。

> ⚠️ 侧载（非应用商店）安装时，Android 13+ 开启无障碍前可能被「受限设置」拦截。
> 请到 **设置 → 应用 → 连点器 → 右上角菜单 → 允许受限设置**，再回到无障碍页面开启本服务。

## 使用方法

1. 开启无障碍服务并打开需要连点的应用，屏幕上显示原来的圆形控制球与十字目标点。
2. **长按控制球**进入定位模式，同时展开 **＋ / －** 两个按钮；此时目标点可以拖动。
3. 点 **＋** 添加目标点，拖动各十字中心到需要点击的位置；点 **－** 删除最后一个目标点。
4. **再次长按控制球**收起加减按钮并锁定位置。也可以直接单击控制球开始，自动收起并锁定。
5. **单击控制球**照常开始 / 停止；多个目标点按编号循环，重新启动从 1 号开始。拖动主球可以移动它及已展开的加减按钮。

点击完成后等待设置的间隔，再点击下一个目标。切换应用或出现系统弹窗时会暂停，返回启动时的应用后继续。屏幕方向/尺寸变化时停止并锁定，需要长按后重新定位。停止时已发出的单次手势可能完成，但不会继续发出下一次。

## 构建

Android 项目，使用 Gradle (Kotlin DSL)：

| 项目 | 值 |
| --- | --- |
| `applicationId` | `com.casual.autoclicker` |
| `minSdk` | 24 |
| `targetSdk` | 32 |
| `compileSdk` | 33 |

```bash
./gradlew assembleDebug      # 生成 debug APK
./gradlew assembleRelease    # 生成 release APK（需配置签名）
./gradlew testDebugUnitTest lintDebug  # 点击顺序/调度回归测试及静态检查
```

构建需要 JDK 11 或 17、Android SDK Platform 33。Debug APK 位于 `app/build/outputs/apk/debug/app-debug.apk`；覆盖已有安装时需使用相同的签名证书。

## 手动验证

- 初始仅显示原来的 45dp 主球和 28dp 目标点；单击照常开始/停止，目标点锁定时不可拖动。
- 新安装后只要求开启无障碍服务；系统的“显示在其他应用上层”列表中无需授权本应用。
- 长按主球展开两个圆形「＋ / －」按钮并允许拖动目标点；再次长按应收起并锁定，松手不应误触开始。
- 展开后添加 3 个目标点并拖到不同位置，验证顺序为 `1 → 2 → 3 → 1`；单击开始应先收起加减按钮。
- 在屏幕边缘展开和拖动主球，确认加减按钮可操作，主球不会因展开而移位。
- 点击停止后等待超过一个间隔，确认不再点击；快速停止/启动仍从 1 号开始。
- 运行中长按应停止并进入定位；删除到 1 个后「－」禁用，目标点恢复无编号的原版样式。
- 停用/重启无障碍服务，确认编号、位置和间隔恢复。
- 在 Android 12 及以上确认点击可穿透标记（包括标记重叠时），切换应用暂停、返回继续。
- 旋转屏幕后确认停止、收起加减按钮并锁定；长按校准位置后可重新启动。
